# 系统规则

初始规则（后续由收盘验证任务自动迭代）：

1. 信息源优先级：公司公告/财报 > 主流财经媒体 > 高质量 X/Twitter 账号 > 普通社媒热度。
2. 交易频率：每天最多 5 个模拟盘建议；信息噪声大或宏观风险高时优先观望。
3. 仓位：单票建议仓位默认不超过 20%，组合总暴露默认不超过 70%；高波动标的下调仓位。
4. 风控：每个建议必须有失效条件/止损；没有清晰止损不建议开仓。
5. 复盘：每日收盘计算组合 P&L、命中率、最大不利波动，并记录错误归因。
6. 连续盈利目标：达到连续 5 个交易日盈利后，进入更长周期样本外验证，不直接建议实盘。

## 待优化方向

- 增加股票工具仓库集成：数据抓取、信号打分、回测、模拟盘持仓同步。
- 增加稳定行情数据源，减少网页延迟/缺失。
- 增加 X/Twitter 账号白名单与可信度评分。

## 2026-05-14 规则迭代（基于 2026-05-13 美股建议验证）

1. 风控优先级上调：收盘盈利但盘中触发止损的建议，模拟盘验证按亏损/止损处理；命中率以风险规则口径为准。
2. 入场过滤新增硬条件：若开盘价已经低于建议止损价，默认取消该买入建议，除非后续重新站回触发位并且止损位同步上移/重新定义。
3. 突破交易新增确认：TSLA 类高波动股突破触发后，必须要求“突破后回踩不破 + 指数/板块同步不弱”，否则仓位上限从 8%-10% 下调到 5%。
4. 中概/港股代理风控：BABA 类 ADR 若日内振幅超过 8% 或低点偏离参考价超过 5%，即使收盘强势，也不得加权为有效强势信号；次日只允许观察或更小仓位。
5. 权重调整：公司/行情确认 40%，技术触发与止损结构 35%，主流新闻 15%，X/Twitter 10%；当 X API 未配置或无法核验时，X 权重临时降为 0%-3%。
6. dexeteryy 来源状态：本轮未能直接采集与建议逐项匹配，可信度维持“待验证/中性偏低”；只有连续记录到方向、时间戳、标的并通过收盘复盘后才提高权重。
